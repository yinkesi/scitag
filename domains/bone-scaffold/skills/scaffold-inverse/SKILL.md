# 骨支架逆设计（output → input）

你的任务：研究者给出性能目标（如 compliance ≤ 某阈值），你给出设计参数的可行区间。

## 步骤

1. **明确目标口径**：与主人确认目标是「越小越好」（compliance）还是区间。
   默认处理 compliance ≤ target 形式。
2. **网格扫描求可行域**：
   `python3 domains/bone-scaffold/scripts/analyze.py inverse --target 8e-11`
   （脚本在 10×10 数据凸包内列出满足条件的 (Vf, θ) 组合，并归并成区间表述）。
3. **模型交叉验证**：用「scaffold-model」的拟合公式在连续域上复核边界，
   与网格扫描结果并列呈现（网格=事实，模型=平滑化），两者出入 >10% 时以网格为准。
4. **边界与外推警示**（必须写）：
   - 可行区间只在数据凸包内有效。对 compliance ≤ target：target 低于全表
     最小值 7.44e-12 时为「数据域内无解」；target ≥ 全表最大值 1.33e-10 时
     为「全部样本满足上限」，可建议收紧约束。两种情况均不需要也不允许外推。
     若目标改为 compliance = target 或指定区间，必须另外判断可行性，不能套用上限约束的结论。
   - 多解时（同一 compliance 可由高 Vf 低角 / 低 Vf 高角 达成），
     列出权衡：高 Vf 牺牲孔隙（渗透/血管化），供主人按临床偏好取舍。
5. **给出推荐点**：在可行域内给 1–2 个代表设计（附对应 IMAGE_ID，方便调拓扑图）。

## 产出格式

按知识库「研究任务口径」T3 的验收口径：可行区间表 + 模型交叉验证 + 权衡说明 + 推荐设计。

## 红线

- 不外推：凸包外一律「无解/需补仿真」，这是逆设计的职业操守。
- 推荐设计必须指向真实存在的 IMAGE_ID 行，不接受插值出来的"虚拟行"。
