# 骨支架函数建模与基础函数分析

你的任务：为 compliance(Vf, θ) 找最简充分的经验公式，并解读每个基函数系数的物理含义。

## 步骤

1. **候选模型族**（全部最小二乘，脚本已内置）：
   - M1 线性：c = a0 + a1·Vf + a2·θ
   - M2 二次：c = b0 + b1·Vf + b2·θ + b3·Vf² + b4·θ²
   - M3 交互：M2 + b5·Vf·θ
   - 若残差随 θ 呈指数增长（COMSOL 数据常见），试 M4：log(c) 上做 M2 再回变换。
2. **拟合**：`python3 domains/bone-scaffold/scripts/analyze.py fit`（默认对 compliance
   做上述模型比较，输出系数与 R²）。permeability 不要拟合（数据字典注记 1）。
3. **模型选择**：报告各模型 R² 与残差形态，按「最简充分」原则选定；
   R² 提升 <2% 不值得加项。
4. **基础函数分析**（写进报告）：
   - 各系数符号/量级与「scaffold-explain」技能的机理预期是否一致；
   - 交互项系数 b5 若显著，说明刚度对各向异性的敏感度随孔隙率放大；
   - 给出公式的适用域：Vf∈[0.25,0.65]、θ∈[0°,45°] 的数据凸包，出界即外推。

## 产出格式

按知识库「研究任务口径」T3 的验收口径：显式公式（系数给 3 位有效数字）+ R² 表 +
系数物理解读 + 适用域声明。

## 红线

- R² 必须脚本算出来，不许目测估计。
- 公式只代表本数据集口径（Fluid objective weight 恒 1e5），推广到其它权重配置
  必须声明未验证。
