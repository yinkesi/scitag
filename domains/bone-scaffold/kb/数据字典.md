# 数据字典

数据集：`domains/bone-scaffold/data/BONE_SCAFFOLD.xlsx`（COMSOL 6.2.0.290 导出，
表头见文件前 4 行元信息，2026-06-30 生成）；配套拓扑图
`data/images/Untitled001.png ~ Untitled100.png`（与行号一一对应）。

## 列定义（100 行 × 7 列）

| 列名 | 含义 | 取值 | 备注 |
| --- | --- | --- | --- |
| IMAGE_ID | 拓扑图文件名 | Untitled001–100.png | 与 data/images/ 一一对应 |
| volume_fraction | 实际固相体积分数 | 0.25–0.65，10 档 | 网格化取值（≈0.044 步长） |
| Load_Angle (deg) | 加载角度 | 0–45°，10 档（0,5,…,45） | 与 volume_fraction 构成 10×10 全因子 |
| Target volume fraction | 目标体积分数 | 与 volume_fraction 相同 | 约束收敛的印证 |
| Fluid objective weight | 流体目标权重 | 恒 1e5 | 本扫描中不变化（与论文 0.1–0.9 权重扫描不同） |
| compliance | 结构顺应性（m/N 量纲按 COMSOL 导出） | 7.44e-12 – 1.33e-10 | 跨 17.9 倍；越小越刚 |
| permeability | 渗透率 | 0.33997073 – 0.33997076 | **相对离散仅 8.5e-8，事实恒定** |

## 数据质量注记（分析前必读）

1. **permeability 在本扫描中不可作为响应变量**：100 行只在第 9–10 位小数上变化。
   任何「permeability 与 input 的关系」拟合都会得到退化的常数函数。
   可能原因：流体目标权重固定为 1e5（优化器把结构目标挤没了）、或导出口径为归一化值。
   若研究渗透率需回 COMSOL 复核口径，不要硬拟合。
2. **可用的输入→输出关系**：compliance = f(volume_fraction, Load_Angle)。
   直观趋势（可用脚本验证）：同一 Vf 下 compliance 随角度单调上升（0° 最刚）；
   同一角度下 Vf 越大 compliance 越小。
3. **全因子结构**：10×10 完整网格，无缺失行；适合直接做方差分析/响应面，
   不需要插值补全。
4. **图像即密度场可视化**：128×128 拓扑（白=固体/黑=孔隙，或反之，用直方图验证），
   图像统计（固相像素占比）应与 volume_fraction 列一致——这是数据自洽性检查的抓手。

## 读取方式

`scripts/analyze.py`（openpyxl 读表，纯 Python 数值实现，无 numpy 依赖）：
`python3 scripts/analyze.py stats|fit|inverse ...`，见脚本头部说明。
