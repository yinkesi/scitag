# 研究任务口径

导师建议（2026-09 微信原话归纳）的三个研究方向，及其在本平台的规范化表述与验收口径。
派活时直接引用本条目的任务编号（T1/T2/T3），避免各 agent 口径漂移。

## T1 吃透论文与数据（全员前置）

- 通读论文方法管线（见「论文方法论」），能复述：为什么用 Brinkman、为什么用 β-VAE、
  损失三项各管什么。
- 通读数据字典，能回答：多少行、哪些列、全因子还是 LHS、permeability 为什么不能用。
- **验收**：不看材料能画出方法管线框图；数据自洽性检查通过
  （图像固相占比 vs volume_fraction 列一致性抽查 ≥ 5 张）。

## T2 可解释性：为什么 output 是这个值（机理归因）

- 对 compliance 建立单变量分组分析：固定 Vf 看 angle 扫描、固定 angle 看 Vf 扫描。
- 给出物理机理解释（载荷路径、杆径有效惯性矩、应力遮挡），不止统计相关。
- 显式区分「数据里看到的相关」与「物理上成立的因果」，不确定处标注。
- **验收**：报告含 (a) 分组统计表 (b) 趋势图描述 (c) 机理段落 (d) 置信度声明。

## T3 函数建模 + 基础函数分析 + 逆设计

- 用基础函数族（线性、二次、交互项、指数）拟合 compliance(Vf, θ)，
  报告各模型 R² 与残差结构，选定最简充分模型。
- 基础函数分析：各基函数系数的物理含义（如角度项系数对应刚度的各向异性衰减率）。
- 逆设计：给定 output 区间（如 compliance ≤ 8e-11），求 input 的可行范围
  （Vf、θ 各自的区间），并在数据凸包内声明适用边界——外推必须打警告。
- **验收**：给出显式公式 + R² + 逆设计区间 + 适用域声明。

## 报告通用格式（所有 agent 的成果都按这个骨架交主人审阅）

```
# <任务标题>
## 结论（3 行以内，先说答案）
## 方法与数据（用了哪些行/哪些假设/哪些脚本）
## 结果（表格 + 公式，数据留痕）
## 机理解释 / 适用边界
## 不确定性与下一步
```
