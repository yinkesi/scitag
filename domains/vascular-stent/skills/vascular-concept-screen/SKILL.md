# 血管介入器件概念筛选（载药 vs 封堵）

你的任务：把一个**病例输入**变成可复核的概念比较与材料建议。先分清装置目标，再算量级，最后给推荐与缺口；不要跳过物理量级直接给结论。

## 步骤

1. **收齐病例输入**（缺哪项就列为假设，不要编）：
   - 肿瘤/病变位置（文本）；
   - 病变/缺损直径（mm）、目标血管直径（mm）、病变长度（mm）；
   - 血压（mmHg）、流量（mL/min，若造影/超声有）；
   - 术式期望：**保通畅地封堵**（覆膜支架）还是**断流栓塞**（封堵器/弹簧圈）？两者成功判据不同。
2. **跑概念筛选**（本机有域包时）：

   ```bash
   python3 domains/vascular-stent/scripts/stent_tool.py concept \
     --location "肝动脉右支供血" --lesion-mm 4 --vessel-mm 3 --length-mm 10 \
     --pressure-mmhg 100 --json
   ```

   若本机没有域包/数据：明确写「未取得计算环境」，并列出需要补的输入；**不得编造载药量或密封力**。
3. **解释 A/B**：
   - A（药物涂层支架）：看"等效口服天数"与"每日剂量比"。若比口服日剂量低 3 个数量级 → 系统性慢病不成立；局部抗炎/抗再狭窄在 DES 量级可行，但属既有临床逻辑。
   - B（封堵/栓塞）：看静压载荷 → 所需密封力 → 材料径向力裕度 → 降解窗分类。注意连续薄环是数量级近似。
4. **给材料短名单与风险**：永久闭塞 vs 临时封堵分别列；说明金属无腐蚀动力学、聚合物只有近似完全吸收时间。
5. **补材料物理指标（FDO 口径，能跑就跑）**：若病例/设计扫描给出释放窗口、服役期、孔口直径，运行：

   ```bash
   python3 domains/vascular-stent/scripts/stent_tool.py fdo \
     --release-days 7 --horizon-days 90 --orifice-mm 0.71 --json
   ```

   输出每种聚合物的 `t_crit`、质量损失（释放末/服役末）、孔口半径漂移、释放指数 `n`、burst 与双约束判定。**这些常数是文献量级占位，必须标注「screening, not measured」**，不能当寿命或临床结论。
6. **出报告**（见下），并明确"下一步验证"（台架泄漏/爆破、迁移、降解；动物闭塞/再通/组织反应；影像与术式确认）。

## 产出格式

```
## 结论（3 行以内：选哪个概念、为什么、差多少量级）
## 病例输入与假设
## A 载药预算（表：载药量 / 等效口服天数 / 每日剂量比 / 判定）
## B 封堵预算（表：缺损面积 / 静压载荷 / 所需密封力 / 材料径向力裕度 / 降解分类）
## 材料物理指标（FDO 表：t_crit / 质量损失 / 孔口漂移 / 释放指数 / 双约束判定；标注占位常数）
## 推荐（含 B1/B2 区分）与数据缺口
## 参考命令与来源
```

## 红线

- 不做影像诊断、不替代医生；肿瘤位置/造影只作病例上下文。
- B1（封堵但保通畅）与 B2（断流栓塞）不能混用同一成功判据。
- 连续薄环径向力 ≠ 成品器械径向力；金属腐蚀/疲劳/血栓/再通数据本库没有。
- 载药量两种口径（涂层体积 / 单位面积）都要报，取保守值；不得声称治疗全身慢病。
- 缺数据写「未取得」，禁止用"看起来合理"的数字填空。
