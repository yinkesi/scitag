# 血管支架计算验证（V0–V5）

你的任务：对一个计算实现做**分层验证**并交一份可复核报告。分清「代码/网格验证（数值实现）」与「真实支架/临床验证」——前者通过不代表后者成立。

## 步骤

1. **明确验证层级与对象**：V0 代码验证（解析解对照）→ V1 网格验证 → V2 耦合验证 → V3 同条件 3D 复算 → V4 实验 → V5 临床。本轮只做能做的层级，其余明确写「未覆盖及原因」。
2. **跑基准（V0）**：

   ```bash
   python3 domains/vascular-stent/scripts/stent_tool.py flow --q 100 --json
   python3 domains/vascular-stent/scripts/stent_tool.py verify --json
   python3 domains/vascular-stent/scripts/stent_tool.py ring --E 44.2 --t 120 --json
   ```

   期望量级（2026-10-18 基准，R=1.5 mm、L=18 mm、ρ=1025 kg/m³、μ=1.5 mPa·s）：
   - 100 mL/min：平均流速 0.2358 m/s、Re≈483.36、压降 22.64 Pa、WSS 0.9431 Pa、中心线 0.471570 m/s；
   - 圆管有限差分相对 L2 误差：原脚本 numpy LU ≈1e-15～1e-13，纯 Python Thomas ≈1e-16～1.6e-15（判据 ≤1e-10，均远过）；
   - 轴对称厚壁管：N=20 位移误差 1.846e-4、N=320 7.210e-7；内壁环向应力误差 N=20 3.402%、N=320 0.217%（判据 ≤2% **针对生产网格**，见下条）。
   **2% 判据要看网格**：粗网格 N=20 的应力误差 3.402% 超 2% 属正常（应力收敛 O(h)、位移 O(h²)），报告必须写"在最细/生产网格上是否满足 2%"并给收敛趋势，不能挑一个网格就说通过。
   若本机没有域包/脚本：**不得编造**，写「未取得计算环境」并给需要主人补齐的清单。
3. **网格验证（V1）**：用 `verify --n 20,40,80,160,320` 看误差随 N 的下降（位移近似二阶）；说明真实支架应在支杆厚度方向留足边界层/接触网格，并以峰值应力与径向力**同时**收敛选网格。
4. **薄环尺度检查（不是径向力）**：`ring` 给的是 `k_line=E t³/(12R³)` 的数量级；`F = k_line·ΔR·1mm` 的量纲是**每 1 mm 轴向长度的力（N）**，不是"N/mm 的刚度"，更不是成品支架径向支撑力。说明开孔/桥筋/摩擦/接触会显著改变有效刚度，成品径向力须台架或 3D 有限元。
5. **对照判据表**：V0 流速 ≤1e-10、位移/应力 ≤2%；V1 相邻网格主要响应变化 ≤2%；V2 质量不平衡 ≤0.1%、穿透 ≤2% 支杆厚度；V4 压降 ≤10%、质量流 ≤1%、径向力归一化 RMSE ≤15%、回弹差 ≤1 个百分点（**内部筛选门槛，不是监管限值**）。
6. **写结论与缺口**：哪些层级已通过、哪些未做、缺哪些输入（真实 CAD、材料塑性/降解参数、台架/体内数据）。

## 产出格式

```
## 结论（3 行以内：什么被验证了，什么没有）
## 验证对象与判据
## 结果（误差表：量 / 解析值 / 数值 / 相对误差 / 判据）
## 收敛性与网格建议
## 未覆盖层级与数据缺口
## 可复跑命令与输入清单
```

## 红线

- 数值实现自检 ≠ 真实支架验证；V0/V1 通过不等于 V4/V5。
- 不把连续薄环、稳态牛顿管流、代理模型输出当设计真值。
- 不隐藏失败：网格不收敛、接触穿透超限、罚刚度敏感、材料数据缺失必须写进报告。
- 15%/10% 是内部筛选门槛，不能写成监管限值或临床安全线。
- 用数值前先跑工具；没有工具/数据就标注缺失，禁止手写"看起来合理"的误差数字。
