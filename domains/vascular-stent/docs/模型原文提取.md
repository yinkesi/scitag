[Heading 1] 1  模型判断与交付边界
参考文献的研究对象是骨科多孔支架，而非血管支架。论文的结构目标是降低柔量和流体耗散，并在 0°–45° 压缩载荷和低雷诺数灌流条件下优化单元结构。该方法适合建立支架微结构筛选器，但血管支架的主要失效路径还包括压握和球囊扩张、血管/斑块接触损伤、脉动流下的低/高剪切、径向支撑衰减、疲劳断裂和降解后的结构失稳。
因此模型分为四个时间尺度。植入展开阶段处理大变形、塑性和接触；心动周期阶段处理脉动流和管壁耦合；长期阶段处理腐蚀或水解及材料性能衰减；最后把计算输出与台架、体外和生命学实验逐项对照。任何代理模型只能在这些物理模型完成验证后用于加速，不能代替验证数据。

[Heading 1] 4  固体力学、接触与器械性能
展开和回弹不能用小应变线弹性处理。支架经历大位移、材料屈服和接触，采用有限变形平衡：
∇ · P + ρs b = 0,   P = ∂W/∂F    (1)
其中 P 是第一类 Piola-Kirchhoff 应力，F 是变形梯度。对 Mg/Zn/Fe 支架采用 J2 塑性；屈服面可取 f = sqrt(3J2) - σy(εp, D)，并将损伤变量 D 与腐蚀质量损失耦合。对 PLLA/PLGA/PCL/PDO，采用可压缩超弹性或粘超弹性模型，并可叠加塑性、损伤和降解。
血管和斑块采用 Holzapfel-Gasser-Ogden 型纤维增强超弹性模型：
W = c/2 (I1-3) + Σα k1α/(2k2α) { exp[k2α ⟨καI1+(1-3κα)I4α-1⟩²] - 1 } + U(J)    (2)
接触采用带摩擦的罚函数或增广拉格朗日法。罚刚度必须做敏感性分析，使最大穿透小于支杆厚度的约2%，同时接触力对罚刚度的变化不应改变主要结论。血管损伤不应仅用von Mises应力代替，应同时报告接触压力、最大主应变和损伤变量。
展开过程的器械性能指标为：
R_r = 100% × (D_release - D_loaded)/D_loaded    (3)
F_s = 100% × (L_initial - L_final)/L_initial    (4)
D_b = 100% × (D_end - D_center)/D_center    (5)
其中 R_r 是径向回弹，F_s 是短缩率，D_b 是狗骨形程度。径向支撑力应由力–径向位移曲线定义，K_r = dF_r/d(ΔR)，不能从弹性模量直接推断。

[Heading 1] 5  血流、管壁耦合与血流指标
原论文的低Re稳态Stokes–Brinkman模型可作为支架内部微尺度筛选器，但不能替代血管腔内的脉动血流。血管支架阶段应求解流固耦合的不可压缩Navier–Stokes方程：
ρf (∂u/∂t + (u-w)·∇u) = -∇p + ∇·[μ(γ̇)(∇u+∇uᵀ)]    (6)
∇·u = 0    (7)
其中 w 是网格速度。血液可按Carreau–Yasuda模型处理：
μ(γ̇) = μ∞ + (μ0-μ∞)[1+(λγ̇)^a]^((n-1)/a)    (8)
入口宜以心动周期流量波形和Womersley型速度剖面驱动，出口采用三元件Windkessel耦合：
P_out = P_C + R_p Q,   C dP_C/dt + P_C/R_d = Q    (9)
壁面剪切应力由近壁速度梯度计算。为避免单一时刻误判，输出周期平均TAWSS、振荡剪切指数OSI和相对停留时间RRT：
τw = μ ∂u_t/∂n|wall    (10)
TAWSS = 1/T ∫0^T |τw| dt    (11)
OSI = 0.5[1 - |∫0^T τw dt| / ∫0^T |τw|dt]    (12)
RRT = 1/[(1-2OSI)TAWSS]    (13)
计算结果要同时报告低剪切面积、高剪切面积、WSS梯度、回流区和支架支杆附近的空间极值。这些指标的临床阈值受血管床和患者条件影响，模型只能给出相对比较，不能自行设定统一安全线。

[Heading 1] 6  降解与生物响应耦合
长期模型采用扩散–反应–力学耦合。腐蚀性离子、氧、水或水解产物满足：
∂ci/∂t + u·∇ci = ∇·(Di∇ci) - Ri(c,σ)    (14)
金属腐蚀前沿可用等效厚度退化表示：
dξ/dt = k_c f(pH,Cl⁻,蛋白,流场,应力) exp[-Q/(RT)]    (15)
聚合物水解可用分子量下降和强度/模量衰减表示：
dMw/dt = -k_h Mw^m    (16)
E(t)=E0 f_D(D),   σy(t)=σy0 g_D(D)    (17)
等效杨氏模量、屈服强度和有效径向刚度随时间更新，再回写到结构模型。这样得到的不是一条孤立的体外质量损失曲线，而是与支杆厚度、局部应力和血流环境耦合的支撑力寿命。

[Heading 1] 7  拓扑优化与代理模型
在保持论文SIMP–Brinkman思路的同时，把目标函数扩展为血管支架专用指标。设计变量包括支架单元拓扑密度、支杆宽度或厚度、桥筋位置、冠部几何和沿长度的开孔分布。优化不是只最小化柔量和流体耗散，而是：
min J = w_s C/C_ref + w_f Φ/Φ_ref + w_τ J_τ + w_r J_R + w_c J_c + w_d J_D    (18)
C 是结构柔量，Φ 是流体耗散，J_τ 是 WSS偏离和空间梯度，J_R 是回弹/径向力误差，J_c 是接触损伤，J_D 是降解寿命偏差。约束至少包括体积分数、最小可制造尺寸、开孔连通性、最大塑性应变、最大接触压力和最小疲劳安全系数。
代理模型应只作为减速器，而不是物理真值。原论文的100个二维样本和130万级可训练单元不足以覆盖血管支架的三维几何、接触和脉动流响应；当前阶段应先做少量物理设计，完成几何收敛和实验校准，再决定是否训练VAE。训练集要按器械几何而不是随机像素拆分，留出未见材料和泊松比进行外部验证。

[Heading 2] 8.2  薄环刚度尺度检查
为快速判断材料和厚度对径向支撑的敏感性，可用连续薄环作为数量级检查：
k_line = E t³ / (12 R³)    (19)
在R=1.5 mm、WE43厚120 μm时，k_line约1.89×10⁶ N/m²；在径向位移0.1 mm时对应0.189 N/mm。PLLA和PLGA在名义厚度180 μm时分别约为0.050和0.043 N/mm。该值不是成品支架的径向力，因为开孔单元、桥筋、摩擦和接触会显著改变有效刚度。

| M5  10–12周 | 多目标优化与代理模型 | Pareto前沿、代理误差和独立复算 | 模型只用于插值并通过留出验证 |

当前最先缺的不是几何优化，而是三组校准数据：支架材料的塑性/降解参数、目标血管的几何与壁厚、以及成品支架的径向力和疲劳曲线。缺少这些数据时，模型可以完成数值实现和趋势比较，但不能给出临床寿命。
[Heading 1] 结论
本项目可继续沿用原论文的结构-流体多目标优化和代理模型思路，但必须重新定义研究对象。建议先完成 V0/V1 代码和网格验证，再接入压握-扩张接触、脉动流和降解；优化器和VAE放在物理模型之后，不应提前成为设计真值。当前解析基准已经证明数值积分链路可用，但还没有完成真实支架的几何、材料和实验校准。
