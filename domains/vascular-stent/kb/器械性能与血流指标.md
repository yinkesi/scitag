# 器械性能与血流指标

## 固体力学与器械性能（展开/回弹阶段）

展开与回弹不能用小应变线弹性：支架经历大位移、屈服与接触。有限变形平衡：

```
∇·P + ρs b = 0,   P = ∂W/∂F          (1)
```

- 金属（Mg/Zn/Fe）：J2 塑性，屈服面可取 `f = sqrt(3J2) - σy(εp, D)`，损伤变量 D 与腐蚀质量损失耦合。
- 聚合物（PLLA/PLGA/PCL/PDO）：可压缩超弹性或粘超弹性，可叠加塑性、损伤与降解。
- 血管/斑块：Holzapfel-Gasser-Ogden 纤维增强超弹性（式 2），含纤维方向与分散参数 κ。
- 接触：摩擦罚函数或增广拉格朗日；罚刚度要做敏感性分析，使最大穿透 < 支杆厚度的 ~2%，且接触力结论不随罚刚度改变。

**器械指标（必须按定义报，不能凭 E 推断）**：

```
R_r = 100% × (D_release - D_loaded) / D_loaded     (3)  径向回弹
F_s = 100% × (L_initial - L_final) / L_initial     (4)  短缩率
D_b = 100% × (D_end - D_center) / D_center         (5)  狗骨形程度
```

- 径向支撑力由**力–径向位移曲线**定义：`K_r = dF_r/d(ΔR)`；**不能从弹性模量直接推断**径向力。
- 血管损伤不能只用 von Mises 应力代替：同时报接触压力、最大主应变、损伤变量。
- 疲劳：循环应力幅/均值、循环次数、失效模式，由脉动疲劳台架校准。

| 输出 | 计算定义 | 对应实验 |
| --- | --- | --- |
| 径向力曲线 | 压握/扩张后的 F_r(ΔR) | 径向力台架、压握-扩张试验 |
| 回弹率 | 式(3) | 直径测量/影像 |
| 短缩率 | 式(4) | 光学测量 |
| 狗骨形 | 式(5) | 扩张影像 |
| 接触损伤 | 接触压力/最大主应变/损伤变量 | 组织学、离体血管 |
| 疲劳寿命 | 应力幅/均值/循环数/失效模式 | 脉动疲劳台架 |

## 血流、管壁耦合与血流指标（心动周期阶段）

支架内部微尺度筛选可用低 Re 稳态 Stokes–Brinkman；但血管腔内的**脉动血流**必须解不可压缩 Navier–Stokes + 管壁耦合：

```
ρf (∂u/∂t + (u-w)·∇u) = -∇p + ∇·[μ(γ̇)(∇u+∇uᵀ)]    (6)
∇·u = 0                                              (7)
```

- 血液可选 Carreau–Yasuda：`μ(γ̇) = μ∞ + (μ0-μ∞)[1+(λγ̇)^a]^((n-1)/a)` (8)。
- 入口：心动周期流量波形 + Womersley 型速度剖面；出口：三元件 Windkessel `P_out = P_C + R_p Q`，`C dP_C/dt + P_C/R_d = Q` (9)。
- 壁面剪切应力 `τw = μ ∂u_t/∂n|wall` (10)；周期统计量：

```
TAWSS = 1/T ∫0^T |τw| dt                                  (11)
OSI   = 0.5[1 - |∫0^T τw dt| / ∫0^T |τw| dt]              (12)
RRT   = 1 / [(1-2·OSI)·TAWSS]                             (13)
```

- 必须同时报告：低剪切面积、高剪切面积、WSS 梯度、回流区、支杆附近空间极值。
- 临床阈值受血管床与患者条件影响：模型只能给**相对比较**，不能自行设定统一安全线。

## 降解与生物响应（长期阶段）

- 扩散–反应–力学耦合：`∂ci/∂t + u·∇ci = ∇·(Di∇ci) - Ri(c,σ)` (14)。
- 金属腐蚀前沿等效厚度：`dξ/dt = k_c f(pH, Cl⁻, 蛋白, 流场, 应力) exp[-Q/(RT)]` (15)。
- 聚合物水解：`dMw/dt = -k_h Mw^m` (16)；`E(t)=E0 f_D(D)`、`σy(t)=σy0 g_D(D)` (17)。
- 等效 E、σy、有效径向刚度随时间更新并回写结构模型 → 得到与支杆厚度、局部应力、血流环境耦合的**支撑力寿命**，而不是孤立的体外质量损失曲线。
- 生物学终点（细胞活性、溶血、凝血、补体、体内组织反应）不能用流体/结构模型外推；须按 ISO 10993 适用终点与实验方案判定。

## 优化与代理模型（最后做）

- 目标函数：`min J = w_s C/C_ref + w_f Φ/Φ_ref + w_τ J_τ + w_r J_R + w_c J_c + w_d J_D` (18)。
- 设计变量：单元拓扑密度、支杆宽度/厚度、桥筋位置、冠部几何、沿长度开孔分布。
- 约束至少含：体积分数、最小可制造尺寸、开孔连通性、最大塑性应变、最大接触压力、最小疲劳安全系数。
- 代理模型只作减速器：原论文 100 个二维样本、130 万级可训练单元不足以覆盖三维几何/接触/脉动流。训练集按器械几何拆分，留出未见材料与泊松比做外部验证。

## 红线

- 连续薄环 `k_line = E t³/(12R³)` 只是数量级检查，**不是成品支架径向力**（开孔、桥筋、摩擦、接触会显著改变有效刚度）。
- 稳态牛顿管流只是**数值基准**，不是患者阈值。
- 不把「模型能跑通」说成「支架已验证」；V0/V1 只是代码与网格验证。
- 不隐藏失败与不确定：接触穿透、罚刚度敏感性、网格不收敛、材料数据缺失都要写进报告。
