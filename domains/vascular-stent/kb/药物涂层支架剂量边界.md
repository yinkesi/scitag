# 药物涂层支架的剂量边界

## 结论先行

涂层支架是**局部给药**器械（µg–几百 µg 量级），不是系统性药物储库。用它治疗高血脂这类需要 mg/天、长期给药的全身慢病，**载药量差 3–4 个数量级**，物理上不成立。局部抗炎/抗再狭窄是可行的——但那正是已上市 DES 的既有逻辑，novelty 不能靠"把支架当药库"，只能靠**可吸收材料 + 释放曲线与降解/愈合窗匹配**。

## 量级计算（示例，参数可替换）

3.0×18 mm 支架量级：涂层表面积 ≈ 1.5 cm²，涂层厚 5 µm，涂层密度 ≈ 1.2 g/cm³，药物质量分数 0.30，单位面积载药 100 µg/cm²：

| 量 | 值 |
| --- | --- |
| 涂层质量 | 0.90 mg |
| 载药（按涂层×分数） | 270 µg |
| 载药（按单位面积） | 150 µg |
| 取较保守值 | **150 µg** |
| 口服他汀 20 mg/day 等效 | 0.0075 天 ≈ **11 分钟** |
| 18 个月平均释放 | 0.28 µg/day ≈ 口服日剂量的 **1.4×10⁻⁵** |

→ 即使全部药物瞬间释放，也只够 11 分钟口服量；分摊到 18 个月更不可能产生系统性疗效。

## 什么时候"药物"是合理的

- **局部抗炎/抗增殖/促内皮化**：靶组织浓度靠局部释放即可达到，DES/DCB（药物球囊）是临床常规；剂量范围正是 10–几百 µg。
- **可吸收支架 + 药物**：创新点在"释放动力学 ↔ 聚合物降解 ↔ 内皮化"三者匹配，而不是系统性慢病治疗。
- **栓塞/化疗栓塞（TACE/DEB）**：药物随栓塞材料局部滞留，属于局部给药；但仍需肿瘤学证据，不能由本域包推出疗效。

## 红线

- 不得声称涂层支架可治疗高血脂/高血压/糖尿病等全身慢病。
- 不得把"载药量按涂层体积算"和"按单位面积算"混用；两者都要报，取保守值。
- 必须同时讨论涂层/聚合物风险（晚期血栓、聚合物炎症、涂层完整性），不能只报载药量。
- 药物释放曲线、组织浓度、药代动力学数据本域包没有；缺数据就写"未取得"。

## 与概念筛选的关系

`stent_tool.py concept` 的 A 分支就是这条计算：给表面积/涂层/载药/口服剂量，直接给出"等效口服时间"与"每日剂量比"，用于在概念阶段否决"系统慢病药物支架"。
